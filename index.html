Decisions I will defend

full records ↗
  1. D-01

    Calculate scores when asked. Do not save them.

    The platform saved a health score for each client. The data behind it changed, and the saved score did not. It became false with no warning. I deleted the feature, although people liked it. Now the system saves raw numbers and calculates the score on request.

  2. D-02

    Only one service can write data.

    The service that the language model uses is read-only. If a number is wrong, only one part of the code can be the cause. Bad model output cannot change the records.

  3. D-03

    New tools are locked by default.

    A new tool is available only to the highest role. A person must give wider access on purpose. If someone forgets, nobody can use the tool. That is safer than everybody using it.
